# AI review runs on the admin's Claude client via MCP; the server does not call an LLM

The five AI review roles (F13) are packaged as prompts or skills in the repo. The admin runs them with their own Claude client. The agent reads the changeset and writes findings through the MCP tool "thêm kết quả rà soát" ("add review result"). The server only stores findings and checks the publish conditions (all 5 roles on the correct revision, no high-severity findings still in "Mở" ("Open") status). Reasons: no API cost, no API key kept on the server, and it uses the operator's existing Claude plan.

## Consequences

- The monthly periodic review must be triggered by the admin (or by a Claude scheduled task). The server cannot run it on its own.
- The server cannot prove that findings were generated by AI. This is acceptable because there is only one admin, and the admin still has to approve every changeset.
