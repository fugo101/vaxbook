# Getting help

VaxBook is maintained on a best-effort basis. There is no response-time commitment.

## Questions about using or building VaxBook

- Read the [`README`](README.md), the [glossary](GLOSSARY.md) and the docs in [`docs/`](docs/) first.
- Search the [existing issues](https://github.com/fugo101/vaxbook/issues?q=is%3Aissue), open and closed.
- If you do not find an answer, use the Question form under [New issue](https://github.com/fugo101/vaxbook/issues/new/choose). GitHub Discussions are not enabled.

## Bugs and feature requests

Use the issue forms under [New issue](https://github.com/fugo101/vaxbook/issues/new/choose). Read [`CONTRIBUTING.md`](CONTRIBUTING.md) before sending a pull request.

## Accessibility barriers

Use the Bug report form with the Area "Accessibility". [`ACCESSIBILITY.md`](ACCESSIBILITY.md) describes the target and what to include.

## Wrong catalog or rule data

If a product, a series or a rule looks wrong, open an issue with the "Catalog or rule data error" form. Name the Source document (the official text the data should follow) and give a Citation, meaning the exact location in that document. A report without a source cannot be acted on.

## Medical advice

VaxBook is a neutral vaccination record with cited recommendations. It is not medical advice and does not replace a professional. For decisions about your own or your child's vaccination, ask a doctor or a vaccination facility.

## Security and conduct

- Security problems: do not use a public issue. Follow [`SECURITY.md`](SECURITY.md).
- Conduct problems: follow [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

## Privacy

Issues are public. Do not paste real vaccination records, real birth dates, emails or other personal data into an issue, pull request or comment. Use made-up data.
